

新增生成函数 patch<Message>(baseWire, patchWire, paths)，用于字段白名单补丁。paths 为 1～32 条已知字段路径，不允许父子重叠、重复或穿过 repeated/scalar；选中重复字段整体替换而非追加，选中单值缺席则清除，显式默认值仍有 presence。子路径仅改变该子字段，保留未选中的兄弟字段。补丁可缺 required，候选完整消息必须满足 required 才返回编码；失败不改调用者输入。补丁未知字段不引入；未受替换的原消息节点保留原未知 wire 顺序，整节点替换或删除时其原子树随之替换或删除。生成模块与演示消费使用相同共享运行时。
